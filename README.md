# Echo

Privacy policy and account deletion pages for the Echo mobile app.

Published with GitHub Pages:

- Privacy policy — https://lcsoftwareapp-rgb.github.io/Echo/privacy.html
- Account deletion — https://lcsoftwareapp-rgb.github.io/Echo/delete-account.html

## Setup

Settings → Pages → Source: **Deploy from a branch** → `main` / `/ (root)`.

The `.nojekyll` file disables Jekyll processing so the HTML is served as-is.

## Editing

Plain static HTML, no build step. Edit and push; Pages redeploys in about a minute.

Update the "Last updated" date at the top of a page whenever its content changes materially.
